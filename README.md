# evolving-test

사내 ERP AI 에이전트를 위한 **SEL(self-evolving loop) 샌드박스 평가 플랫폼** 설계 문서 모음.

Phoenix에 쌓인 에이전트 trace를 분석하고, 실데이터 없는 합성 업무 환경(가짜 SAP·문서·페르소나)과 시나리오·정답을 만든 뒤, 그 위에서 에이전트 버전을 테스트·평가한다. 샌드박스는 비즈니스 영역이 직접 열어 쓰는 것을 목표로 한다.

## 핵심 설계 결정

- **정답은 합성 세계에서 계산**하고, 규칙으로 채점하는 것을 우선한다 (τ-bench, AppWorld 방식).
- **SAP 자격증명이 없는 별도 배포 샌드박스 Gateway**를 쓴다. 운영 Gateway에 모드 플래그를 다는 방식은 플래그가 빠지면 운영으로 나간다(fail-open).
- 채점 입력은 **실행기가 직접 수집**한다. Phoenix는 열람에만 쓴다.
- **평가 하네스를 생성 자동화보다 먼저** 만든다. M2a(조회 업무 1개, 단일 턴 10개, 규칙 채점)가 첫 게이트다.
- 실행은 자동, 판단(suite 승인·표본 점검·배포 결정)은 사람이 한다.
